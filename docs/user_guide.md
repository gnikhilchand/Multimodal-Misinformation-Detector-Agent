# User Guide (Non-Technical Users)

## 1. Introduction
Welcome to the Multimodal Misinformation Detector! This tool helps you identify misinformation in both text claims and images. Whether you're verifying a news article or checking the authenticity of an image, this guide will walk you through the process.

## 2. Accessing the Tool
The Multimodal Misinformation Detector is hosted on Hugging Face Spaces. You can access it via the following link:
[Hugging Face Spaces - Multimodal Misinformation Detector](https://huggingface.co/spaces/group9-dsailab/multimodal_misinfo_detector)

## 3. Using the Text Detector
1. **Navigate to the Text Detector Tab**: Once on the Hugging Face Space, select the "Text Detector" tab.
2. **Input Your Text Claim**: Enter the text claim you want to verify in the provided text box.
3. **Submit for Analysis**: Click the "Submit" button to start the verification process
4. **View Results**: The tool will display whether the claim is REAL or FAKE, along with supporting evidence and an explanation generated by a language model.

## 4. Using the Image Detector
1. **Navigate to the Image Detector Tab**: Select the "Image Detector" tab on the Hugging Face Space.
2. **Upload Your Image**: Click the "Upload" button to select an image file
3. **Submit for Analysis**: After uploading, click the "Submit" button to analyze the image.
4. **View Results**: The tool will indicate whether the image is REAL or FAKE

## 5. Understanding the Output
- **Verdict**: Indicates whether the input (text or image) is REAL or FAKE.
- **Confidence Score**: A numerical value representing the model's confidence in its verdict.
- **Explanation**: A detailed explanation provided by a language model, outlining the reasoning behind the verdict.

## 6. Troubleshooting

- If the “Classify Claim” button is disabled, ensure all three API keys are entered.
- If the app fails to load, refresh the Space or restart the kernel (local use).
- If “Error: No relevant evidence found.” appears, retry with a clearer claim.
